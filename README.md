# コハク便ダッシュ

**ver. 1.1.0**

ブラウザだけで遊べる3レーンの配達ラン。
「ほかのゲーム」枠の見た目・アニメーション改善シリーズ、3本目です。

## 方針

ルール（3レーン・星を集める・バリケードで終了・5つごとに報酬UP・だんだん速くなる・ベスト記録）は**従来どおり**。
見た目・アニメーション・画面サイズ対応だけを作り直しました。

## 変えたところ

### 見た目

- **コハク（キツネの配達便）を描きおろした** — 耳・しっぽ・背中の配達ボックスまで描いたオリジナルキャラ。
  走るときに小さく上下に揺れます。
- **道路を作り込んだ** — 遠くの街の明かり、ガードレール、流れるレーン区切り。
  夕暮れの道路が奥へ伸びていくようになりました。
- **星を描き直した** — 5つの角のある星が回りながら光ります。
  金星（+25）はひと回り大きく、光も強くしてあります。
- **バリケードを描き直した** — 白黒の縞模様に、赤く点滅する反射ランプ。
  遠くからでも「危ない」と分かります。

### アニメーション

- **レーン移動** — コハクがスッと横に寄り、少し傾きます。
- **星を取った瞬間** — 金色の星が飛び散り、軽やかな音が鳴ります。
- **クラッシュ** — 画面が大きく揺れ、赤と金の火花が散ります。
- **カウントダウン** — 開始前に「3・2・1・GO!」が弾けて出ます。
- **HUD** — 配達コンボがバーで伸びるので、あと何個で報酬UPかひと目でわかります。

### その他

- **音** — Web Audio で合成した効果音（レーン移動／星／クラッシュ／カウントダウン）。
  外部ファイルなしで鳴ります。
- **操作** — 画面の左半分をタップで左、右半分で右。
  PCは `←` `→` キー。スペースでも開始できます。
- **画面サイズ対応** — スマホの縦・横・PCに合わせて、フィールドが入りきる最大サイズになります。
- **ベスト記録は保存されます**（localStorage）。
- **動きを控えめに設定している端末** — OSで「動きを減らす」を選んでいると、アニメーションが止まります。

## 変えていない中身

- 3レーン（左・中・右）
- 安全なレ―ンに星、他のレーンにバリケード
- 星を取ると点数、5個つなげるごとに報酬UP
- 金星（寄り道ルート）は +25
- だんだん速くなる（上限あり）
- バリケードに当たると終了
